# Machine Learning

Study of machine learning methods, implemented with [scikit-learn](https://scikit-learn.org/). The repository is organized into projects that introduce model development, preprocessing, and evaluation.

[![Scikit-learn](https://img.shields.io/badge/-scikit--learn-%23F7931E?logo=scikit-learn&logoColor=white)](#)

## Projects

### 1. Introduction

Supervised learning workflows, including feature and target selection, data leakage, data splitting, and cross-validation.

Key scikit-learn methods: `train_test_split`, `cross_val_score`, and `DecisionTreeClassifier`.

### 2. Linear Regression

Covers simple and multiple linear regression for house-price prediction, including ordinary least squares (OLS), train/test evaluation, and regression metrics.

Key scikit-learn methods: `LinearRegression`, `train_test_split`, `mean_absolute_error`, `mean_squared_error`, and `r2_score`.

### 3. KNN, Decision Trees, and Random Forests

Applies regression models to apartment-rent prediction. Covers __numerical__ and __categorical__ preprocessing, pipelines, and hyperparameter search.

Key scikit-learn methods: `KNeighborsRegressor`, `DecisionTreeRegressor`, `RandomForestRegressor`, `ColumnTransformer`, `Pipeline`, `StandardScaler`, `OneHotEncoder` and `OrdinalEncoder`.

## What's next

The repository will expand to cover machine learning more broadly. The next planned topics are classification and a deeper study of logistic regression.
